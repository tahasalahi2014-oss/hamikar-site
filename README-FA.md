# حامی کار — راهنمای توسعه

## وضعیت فعلی
- صفحات رابط کاربری فارسی و راست‌چین در فایل‌های HTML و پوشه `assets/` قرار دارند.
- یک اسکلت اولیه API در `src/server.js` و مدل‌های پایگاه داده PostgreSQL در `prisma/schema.prisma` اضافه شده است.
- ثبت‌نام/ورود با رمز عبور، فهرست خدمات، ثبت سفارش و کنترل دسترسی پایه در API پیاده‌سازی اولیه شده‌اند.

## اجرای محلی API
1. Node.js نسخه ۲۰ یا بالاتر و PostgreSQL نصب کنید.
2. `.env.example` را به `.env` کپی کنید و `DATABASE_URL` و یک `JWT_SECRET` تصادفی و قوی تنظیم کنید.
3. اجرا کنید: `npm install`
4. اجرا کنید: `npm run db:generate`
5. برای ساخت migration اولیه در محیط توسعه: `npx prisma migrate dev --name init`
6. سرور: `npm run dev`
7. بررسی سلامت: `GET /api/health`

## صفحات و پنل‌ها
- صفحه اصلی، خدمات، تماس، درباره ما و صفحات خدمات کارگران/کارفرمایان
- لوگوی برداری در `assets/logo.svg`
- ورود و ثبت‌نام: `login.html` و `register.html`
- پنل مشتری برای ثبت درخواست و مشاهده وضعیت: `dashboard.html`
- رابط مدیریت پرونده‌ها: `admin.html`
- اسکریپت اولیه ایجاد مدیر: متغیرهای `ADMIN_NAME`، `ADMIN_PHONE` و `ADMIN_PASSWORD` را فقط در فایل محلی و خصوصی `.env` تنظیم کنید؛ رمز باید دست‌کم ۱۴ نویسه داشته باشد؛ سپس `npm run admin:create` را اجرا کنید. این فرمان می‌تواند حساب همان شماره را به مدیر تبدیل کند، پس فقط توسط مالک سامانه اجرا شود.

## نکات مهم پیش از بهره‌برداری عمومی
این مخزن هنوز نسخه آماده انتشار تجاری نیست. مسیر پرداخت واقعی و تأیید callback درگاه، پیامک، بارگذاری و دانلود امن فایل، رزرو تقویم، گفت‌وگوی زنده، رسید قابل دانلود، سیاست لغو و بازپرداخت، پنل مشتری و رابط اولیه مدیریت اکنون اضافه شده‌اند، اما هنوز کامل و آزمون‌شده نیستند؛ تست‌های یکپارچه، migration بازبینی‌شده، مانیتورینگ و پشتیبان‌گیری خودکار هنوز نیازمند تکمیل و آزمون‌اند. API فعلی فایل آپلود نمی‌کند و نباید برای دریافت مدارک حساس در معرض اینترنت قرار گیرد.

- هرگز `.env`، رمزها، کلید درگاه یا اطلاعات مشتری را commit نکنید.
- نقش مدیر نباید از مسیر ثبت‌نام عمومی قابل انتخاب باشد؛ ایجاد مدیر فقط از رویه امن عملیاتی انجام شود.
- پیش از تولید، CORS، HTTPS، rate limit، نگهداری امن توکن، سیاست حذف اطلاعات و الزامات حقوقی/مالی را بررسی کنید.
- قیمت‌ها در پایگاه داده به ریال ذخیره می‌شوند؛ نمایش تومان باید در رابط کاربری صریح و بدون ابهام باشد.
- متن‌های حریم خصوصی و شرایط استفاده پیش‌نویس هستند و باید قبل از انتشار تأیید شوند.
